# Verdex — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Venture investor / IC member

- As an investment partner, I want a graded capability band with factor decomposition before term sheet, so that I do not price a rules engine as if it were a learning system.
- As an associate, I want to record whether the company’s historic data still trains the next algorithm version, so that I catch chatbot-style data decay early.
- As an IC member, I want the pack to list unknowns explicitly, so that we do not treat silence on talent retention as a pass.
- As a partner, I want grades to expire unless revalidated at follow-on, so that Series A evidence is not silently reused at Series B.

### Technical diligence advisor

- As a technical advisor, I want to mark a claimed ML system as non-ML automation with a cited basis, so that marketing language cannot override the score.
- As a technical advisor, I want to score path-to-performance against a human baseline relevant to the domain, so that “95% accurate” is judged against the right bar.
- As a technical advisor, I want to attempt to award an advanced band without artefacts and have the system refuse, so that provisional scores cannot be published as final.

### Corporate strategy / vendor assurance

- As a strategy lead, I want to compare two vendors on data advantage and distance from monoliths, so that I see who is renting a hyperscaler API and who owns a compounding dataset.
- As a vendor assurance officer, I want a challenge review when a production incident contradicts the diligence grade, so that the scorecard updates with history preserved.

### Portfolio value-creation lead

- As a value-creation lead, I want post-investment monitoring of talent census and data-licence status, so that capability decay triggers an intervention before the next fundraise narrative.

### Platform administrator / compliance

- As a compliance officer, I want an immutable log of who changed a factor score and why, so that an LP diligence on our process has a trail.
- As an administrator, I want clean-room access for sensitive evidence with named NDAs, so that raw customer data never sits in the diligence store.
